How It Works

Check-In

Students can mark attendance from any device with GPS enabled.

Key Features

🎯

Location-Based Verification

Using GPS and Haversine calculations to verify student location with customizable radius.

👥

Role-Based Access

Students, Lecturers, and Admins have tailored interfaces and permissions.

📊

Real-Time Dashboards

View attendance statistics and reports instantly.

🔒

Security Controls

Duplicate prevention, device tracking, and session management.

📈

Analytics & Reports

Track attendance patterns and generate comprehensive reports.

📱

Mobile Responsive

Fully responsive design works on desktop, tablet, and mobile.
