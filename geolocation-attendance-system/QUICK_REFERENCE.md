# 📍 Quick Reference: Location Selection

## Three Ways to Set Venue Location

### 🎯 Method 1: Campus Buildings (⭐ FASTEST)
**Best for:** Creating sessions at known campus venues

```
1. Click "Create Session" tab
2. In Location Selection: click [🏫 Campus Buildings]
3. Click a building button:
   🏢 CSC Building       💻 Computer Lab 1
   🎤 Auditorium        📚 Library
   ⚽ Sports Complex     🔬 Science Lab
4. Coordinates auto-populate ✓
5. Click "Create Session"
```
**⏱️ TIME: 30 seconds**

---

### 📡 Method 2: Use GPS (⚡ MOST ACCURATE)
**Best for:** Creating sessions at your current location

```
1. Click "Create Session" tab
2. In Location Selection: click [📡 Use GPS]
3. Click [📍 Get Current Location (GPS)]
4. Allow browser location permission
5. Coordinates auto-populate ✓
6. Click "Create Session"
```
**⏱️ TIME: 10-20 seconds**  
**📍 ACCURACY: ±5-10 meters**

---

### 📌 Method 3: Manual Entry (🎓 CUSTOM LOCATIONS)
**Best for:** Venues outside campus or custom locations

```
1. Click "Create Session" tab
2. In Location Selection: click [📌 Manual Entry]
3. Get coordinates:
   • Open Google Maps
   • Right-click location
   • Coordinates appear at top
   • Copy the coordinates
4. Paste into fields:
   Latitude:  [paste here]
   Longitude: [paste here]
5. Live preview updates ✓
6. Click "Create Session"
```
**⏱️ TIME: 15-20 seconds**

## ⏱️ Attendance Radius Options

Quick-select buttons:
- **📍 5m** - Single classroom (very small)
- **📍 10m** - Standard room (default)
- **📍 20m** - Large hall or outdoor area

Or manually enter: 1-100 meters

---

## 💡 Pro Tips

✅ **Campus locations are fastest** - Use them when available  
✅ **GPS works best indoors** - Refresh if location seems off  
✅ **Paste from Maps** - Right-click → coordinates copy automatically  
✅ **Preview shows before create** - Verify location looks correct  
✅ **All methods work offline** - No internet needed for campus preset  

---

## 🚀 Typical Workflow

### Create Session in 30 Seconds:

1. ➕ Click "Create Session"
2. 📚 Select unit (e.g., CSC301)
3. 📅 Pick date & time
4. 🏢 Type venue name
5. 🏫 Click Campus Buildings
6. 🎯 Click building (auto-fill!)
7. ✅ Click "Create Session"

**DONE! Students can now mark attendance.**

## ❓ Need Help?

| Issue | Solution |
|-------|----------|

| Coordinates look wrong | Verify on map, re-enter if needed |
